Embed the Eligibility Tool on your website

Add the “Can I vote?” eligibility tool to any page with a link or one small piece of code. It shows only the tool - no menus, header or footer.

On this page

1Create your link and code

In the WordPress admin open RYV Forms → Embed & Share. Choose how the tool should look; the live preview on the right updates as you go, with Desktop, Tablet and Phone views.

SettingWhat it does
FormWhich questionnaire to embed (for example the English or Spanish edition).
Start atPick a single state to skip the “Select your state” question. Leave it on the state picker to cover all states.
LookSame as the website (default): title, description, step list and note on the left, the question card on the right - just like the home page. Minimal: only the questions, simple styling.
LayoutLike the website (default), all questions stacked one under another, or one question at a time.
TextOptional: your own title, description, button labels (Start Over, Continue, Submit, dropdown hint) and the note under the steps. Leave blank to keep the wording of the website.
ShowTurn the form title, description, “Start Over” button and the padding around the tool on or off.
AlignmentMinimal look only. Left (default) keeps title, description and questions in one column. Centered centers all of them.
Content widthMinimal look only: compact, or fill the whole frame.
ColorsOptional accent, secondary, text and background colors to match your site.
Frame heightAutomatic grows with the content (adds one small script). Fixed uses a set height and scrolls inside.

Copy the link or the code

The Share box gives you a link (opens the tool on its own page) and the embed code to paste into a website.

2Add it to your website

Option A - share the link

The simplest option. Link to the address from the Share box, for example:

https://your-site.org/embed/voting-rights/

Option B - embed it with the code

Paste the code where you want the tool to appear:

<iframe src="https://your-site.org/embed/voting-rights/"
  title="Can I Vote?"
  width="100%" height="700"
  style="border:0;width:100%;max-width:100%;"
  loading="lazy" referrerpolicy="strict-origin-when-cross-origin"
  data-ryv-embed></iframe>
<script src="https://your-site.org/wp-content/plugins/ryv-eligibility-tool/assets/js/embed.js" async></script>

Use exactly the code from your Share box - it already has the right address. The small script line makes the frame grow and shrink with the questions, so your visitors never see a scrollbar.

3Options you can change

Everything in the Customize panel is also available as a setting on the link. Add them after ?, joined with &.

Add to the linkResult
?state=alabamaOpens on that state’s first question.
?title=0Hide the title.
?description=0Hide the description.
?title=0&description=0Questions only.
?title_text=Can%20you%20vote%3FYour own title (plain text, up to 160 characters).
?description_text=Answer%20a%20few%20questionsYour own description (plain text, up to 400 characters).
?label_start_over=ResetReword the “Start Over” button. Also label_continue, label_submit and label_placeholder (the dropdown hint).
?layout=wizardOne question at a time (also layout=stacked; by default it follows the website).
?look=plainMinimal look: just the questions.
?note=0Hide the note under the steps (or ?note=Your%20text for your own).
?look=plain&align=centerMinimal look only: center title, description and questions.
?look=plain&fit=fullMinimal look only: use the full width of the frame.
?restart=0Hide the “Start Over” button.
?pad=0No padding around the tool.
?primary=0b4f7aAccent color (also secondary, text, bg; hex without #).

Example: one state, questions and steps only

https://your-site.org/embed/voting-rights/?state=alabama&title=0&description=0&note=0

4Who may embed it

Under Access & security (see the screenshot above) administrators decide:

  • Allow the tool to be embedded - switch off to disable every link and frame at once.
  • Which websites may embed it - Any website, or only the websites listed (recommended once you know your partners). One per line; use *.example.org to include all subdomains.
The embedded pages are hidden from search engines, and visitor progress logging is anonymous (no IP addresses or personal identifiers are stored).

5Troubleshooting

ProblemWhat to check
The frame is blankYour website address must be on the allowed list (or the setting must be “Any website”). Also ask the site’s host whether a firewall or CDN adds its own X-Frame-Options header; it must be exempted for the /embed/ path.
“Not found” pageEmbedding is switched off, the form is still a draft, or the address is mistyped.
A scrollbar appears inside the frameMake sure the script line from the Share box is on the page, or increase the frame height.
The link does not open after an updateAn administrator should open Settings → Permalinks and click Save once.
Colors or fonts look differentSet the accent/text colors in the Customize panel to match your site.
